What to scrobble

Videos from local files are scrobbled only when they have artist and title tags. Live streams and internet radio are scrobbled after 30 seconds, since their length is unknown; radio song by song. Changes apply from the next file.

By default, as in Web Scrobbler, a track is scrobbled only if Last.fm knows its artist and title. This also filters out wrong guesses from file names and video titles. Turn this on to scrobble everything (Web Scrobbler's "Force track recognition").

yt-dlp

Online Media only passes the video title to the player. With this on, the plugin asks yt-dlp for the music metadata (about 2 seconds per video). With it off, only the video title is used.

Leave empty to use /opt/homebrew/bin/yt-dlp, /usr/local/bin/yt-dlp or the copy bundled with IINA, in that order.

Other

The debug log is written to the plugin's data folder (~/Library/Application Support/com.colliderli.iina/plugins/.data/) and helps when reporting a problem. It never contains your Last.fm session key.
